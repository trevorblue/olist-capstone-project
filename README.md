# Olist Brazilian E-Commerce Capstone Project

End of Semester Group Capstone — Data Analytics & Visualization

## 🎯 Project Overview
This project analyzes the Brazilian Olist E-Commerce Public Dataset to understand:
- Delivery delays by region and category
- Customer dissatisfaction drivers
- Payment method impact on revenue
- Seller performance issues

The final output includes cleaned datasets, EDA notebooks, and a 5-page Power BI dashboard.

Dataset Source:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## 📁 Repository Structure
- data/raw → Original Kaggle CSV files (not committed)
- data/processed → Cleaned master dataset
- notebooks → Data cleaning and EDA notebooks
- powerbi → Power BI dashboard and screenshots
- presentation → Final presentation
- docs → Methodology and documentation

## 🚀 How to Run
1. Download Kaggle data into `data/raw/`
2. Install dependencies: `pip install -r requirements.txt`
3. Run notebooks in order (01 → 04)
4. Load cleaned CSV into Power BI
